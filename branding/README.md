# AegisGuard Brand Assets

Professional identity for AegisGuard (AI-Powered Autonomous Security Testing Platform).

## Contents

| Path | Use |
|------|-----|
| `svg/logo-mark.svg` | Primary mark on dark square |
| `svg/logo-transparent.svg` | Shield mark, transparent background |
| `svg/logo-light.svg` | Mark for light backgrounds |
| `svg/logo-wordmark-*.svg` | Mark + wordmark |
| `png/` | Raster exports used by the app |
| `favicon/` | Browser / docs favicons |
| `cli/` | Terminal ASCII banners |

## Palette

- Emerald accent: `#10b981` / `#34d399` / `#059669`
- Dark surface: `#0b1220`
- Light surface: `#f8fafc`
- Text on dark: `#ecfdf5`
